Publication images
==================

One image per publication. Put PNG files here.

Filename convention:
    YYYY_FirstThreeWordsOfTitle.png
    e.g. 2026_TangibleServiceBlueprints.png

The filename is read from the "image" field of each entry in
data/publications.json. If you leave "image" blank, the site
automatically looks for the conventional name above (year +
the first three words of the title, in CamelCase, punctuation
removed). Until a matching file exists, a striped placeholder
with the expected filename is shown.
