05 — Layout & spacing

Container

Max width 1240px, 24px side gutters at every size. Header height 76px.

Spacing scale

4 · 8 · 12 · 16 · 24 · 32 · 56 · 80 · 96

Section padding uses clamp(40px, 6vw, 80px) top, 96px bottom.

Rules

2px black rule opens a section or list; 1px #E5E5E5 divides items inside it. No shadows, no radii, no gradients.

Responsive

Content grids use auto-fit / auto-fill minmax, so they reflow without breakpoints. One breakpoint only: 880px for the nav.

06 — Data & maintenance

data/publications.json

id, year, type (Conference / Journal), title, authors[], venue, venueShort, award, links{pdf, doi, video}. Grouped by year automatically; author names matching a member surface on that member's page.

data/patents.json

id, title, inventors[], number, country, status (Filed / Registered), date.

data/members.json

id, name, nameKo, group (professor · research-professor · postdoc · phd · ms · undergrad), position, email, since, interests[], bio, education[], photo. Group order and headings are fixed; empty groups disappear. Each entry gets its own page at #/members/<id>.

data/news.json

id, date, category (Notice · Award · People · Project · Patent · Talk), title, body, pinned. Turn on Admin mode in Tweaks to write, edit, or delete posts in the browser, then “Copy news.json” and paste the result back into the file.
