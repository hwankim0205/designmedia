Member images
=============

One image per member. Put PNG files here.

Filename convention:
    firstname_lastname.png
    e.g. yuna_cho.png

The filename is read from the "photo" field of each entry in
data/members.json. If you leave "photo" blank, the site
automatically looks for the conventional name above (first and
last name, lowercase, joined with an underscore). Until a
matching file exists, a striped placeholder with the expected
filename is shown.

A 4:5 portrait crop works best.
